JOGABILIDADE

Controles e movimento

O jogo acompanha as teclas pressionadas e modifica a coordenada horizontal da Imani.

keydown identifica a tecla; keyup identifica quando ela foi solta. O loop aplica a posição.

ONDE ENCONTRAR NO PROJETO

// 6. TECLAS PRESSIONADAS e function movimentar().

JavaScript 
if (event.key === "ArrowRight" || event.key.toLowerCase() === "d") {
  direita = true;
  direcao = "direita";
}

if (direita) { posicaoX += 5; }
if (esquerda) { posicaoX -= 5; }
imani.style.left = posicaoX + "px";
✦

Para lembrar: A tecla não move a imagem sozinha: ela altera uma variável que o jogo consulta.

04

JOGABILIDADE

Pulo e gravidade

Imani recebe um impulso para subir e uma aceleração que a faz cair.

A velocidade vertical diminui a cada atualização. O código limita a altura mínima e impede pulos repetidos no ar.

ONDE ENCONTRAR NO PROJETO

// 5. CONFIGURAÇÕES DO JOGO e function movimentar().

JavaScript 
const gravidade = 0.8;
const forcaPulo = 14;
const chao = 85;

velocidadeY = forcaPulo;
pulando = true;

posicaoY += velocidadeY;
velocidadeY -= gravidade;

if (posicaoY <= chao) {
  posicaoY = chao;
  velocidadeY = 0;
  pulando = false;
}
✦

Para lembrar: Não é uma biblioteca de física: são cálculos simples feitos em JavaScript.

06

COMBATE

Ataque com Nahara e colisões

O jogo identifica acertos verificando a sobreposição das áreas de ataque e do inimigo.

getBoundingClientRect() fornece as coordenadas dos elementos. O ataque tem intervalo mínimo de 450 ms.

ONDE ENCONTRAR NO PROJETO

// 9. ATAQUE DA IMANI CONTRA O INIMIGO.

JavaScript 
const areaAtaque = ataque.getBoundingClientRect();
const areaInimigo = inimigo.getBoundingClientRect();

const acertou =
  areaAtaque.right > areaInimigo.left &&
  areaAtaque.left < areaInimigo.right &&
  areaAtaque.bottom > areaInimigo.top &&
  areaAtaque.top < areaInimigo.bottom;

if (acertou) vidaInimigo--;
✦

Para lembrar: Hitbox = região retangular usada para detectar colisão.

07

COMBATE

Comportamento dos Véus

Os Véus perseguem a Imani e calculam de que lado ela está.

A diferença entre os centros define a direção, a distância define quando perseguir/atacar e Math.random() permite uma investida ocasional.

ONDE ENCONTRAR NO PROJETO

// MOVIMENTO DO INIMIGO dentro de function movimentar().

JavaScript 
const diferenca = centroImani - centroVeu;
const distancia = Math.abs(diferenca);

if (diferenca > 0) direcaoInimigo = "direita";
else if (diferenca < 0) direcaoInimigo = "esquerda";

if (distancia > 55 && !golpeVisivel) {
  if (direcaoInimigo === "direita") posicaoInimigoX += velocidadeAtual;
  else posicaoInimigoX -= velocidadeAtual;
}
✦

Para lembrar: Math.abs() retorna uma distância positiva; Math.random() sorteia a chance de investida.

Vida, dano e invulnerabilidade

A Imani inicia com três corações e perde vida quando o ataque inimigo acerta.

Após receber dano, uma variável bloqueia novos danos por 700 ms; a interface é atualizada por uma função.

ONDE ENCONTRAR NO PROJETO

// 10. ATAQUE DO INIMIGO CONTRA A IMANI e function atualizarVida().

JavaScript 
vidaImani--;
atualizarVida();

imaniInvulneravel = true;
setTimeout(function () {
  imani.style.opacity = "1";
  imaniInvulneravel = false;
}, 700);
✦

Para lembrar: Ao chegar a zero, finalizarJogo(false) abre a tela de derrota.

09

COMBATE

Ressonância dourada

Acertar ataques recarrega a habilidade; com a barra cheia, R ativa um golpe especial.

Cada acerto normal gera 50 pontos, com limite de 100. O CSS recebe a porcentagem da barra; o dano especial depende da distância.

ONDE ENCONTRAR NO PROJETO

// ATUALIZAR BARRA DE RESSONÂNCIA e function verificarRessonancia().

JavaScript 
let energiaAtual = 0;
const energiaMaxima = 100;
const energiaPorGolpe = 50;

energiaAtual += energiaPorGolpe;
const porcentagem = (energiaAtual / energiaMaxima) * 100;
energiaRessonancia.style.width = porcentagem + "%";

if (distancia <= 130) vidaInimigo--;
✦

Para lembrar: A Ressonância é DOURADA; os efeitos de ataque de Nahara são separados.

Glossário de comandos

Os termos de JavaScript, HTML e CSS que aparecem no IMANI.

let

Variável que pode receber novos valores.

const

Variável que não pode ser reatribuída.

function

Agrupa instruções reutilizáveis.

if / else

Decidem o que fazer conforme condições.

true / false

Valores verdadeiro ou falso.

===

Compara valores e tipos.

&&

Operador lógico E.

||

Operador lógico OU.

!

Inverte um valor booleano.

++ / --

Aumenta ou diminui uma unidade.

+= / -=

Soma ou subtrai e atualiza a variável.

return

Encerra a execução de uma função.

getElementById()

Encontra um elemento pelo identificador.

addEventListener()

Detecta eventos, como teclas e cliques.

getBoundingClientRect()

Obtém posição e dimensões de um elemento.

setTimeout()

Executa uma ação após um intervalo.

setInterval()

Repete ações em intervalos.

requestAnimationFrame()

Agenda a próxima atualização visual.

Math.abs()

Obtém o valor absoluto.

Math.random()

Gera um número aleatório.

classList.add()/remove()

Adiciona ou remove uma classe CSS.

textContent

Lê ou modifica o texto de um elemento.

style.display

Controla a visibilidade de um elemento.

location.reload()

Recarrega a página.
